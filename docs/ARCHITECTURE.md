# Architecture

Statement X-Ray is a single static web page. There is no server, build toolchain, database or
package dependency. Everything that happens to a seller's statement happens in their own browser tab.

## Components

```
index.html            the whole app: markup, CSS, and two inline scripts
  <script id="core">  SALE config + the Core module (pure logic, no DOM)
  <script>            UI: rendering, file loading, paywall, clipboard
build.sh              wraps index.html in a full HTML document -> docs/index.html
docs/                 GitHub Pages web root (published to https://xray.ausiejus.lt)
  index.html          generated by build.sh; do not edit by hand
  CNAME               custom domain for GitHub Pages
  _config.yml         keeps the project docs out of the published site
SETUP.md              operator guide: Gumroad product, hosting, test purchase
```

### `Core` (index.html, `<script id="core">`)

Pure functions with no DOM access, so they can be extracted and run in Node:

| Function | Role |
|---|---|
| `parseCSV(text)` | Small RFC 4180-style parser (quoted fields, `""` escapes, CRLF/LF, BOM). |
| `money(s)` | Turns `"$1,234.56"`, `"-€2.00"`, `"(1.20)"`, `"1.234,56 €"` or `"--"` into a number. |
| `monthKey(s)` | Normalises ISO, "May 1, 2026", "1 May 2026" and `d/m/y` dates to `YYYY-MM`. |
| `findColumns(header)` | Finds Date/Type/Title/Info/Currency/Amount/Fees/Net columns by fuzzy header name. |
| `classify(type, title)` | Maps each row to a kind: sale, refund, a fee category (`CATS`), deposit, tax or adjust. |
| `analyze(files)` | Combines files, deduplicates rows, picks the main currency, and totals by category, month and order. |
| `sample()` | Generates the deterministic made-up shop shown on first load. |
| `verifyLicense(key, opts)` | Calls Gumroad's licence API. `fetchFn` is injectable for testing. |

### UI script

- `render(report, mode)` draws the answer sentence, the money bar, the ledger, notes, the SVG
  monthly chart and the order table. `mode` is `sample`, `preview` (`#paywall`) or `real`.
- `loadFiles()` handles the file picker and drag-and-drop. It accepts only CSV files under 50 MB.
- `applyLock()`, `unlock()` and `recheckSavedKey()` run the paywall (see below).
- The copy button puts tab-separated totals on the clipboard for spreadsheets.

## Data flow

```
 Etsy CSV files ──(File picker / drag-drop)──► File.text() in memory
                                                   │
                                     Core.analyze ─┤ parseCSV → findColumns → classify → totals
                                                   ▼
                                     render() → DOM (strings from the CSV escaped with esc())
                                                   │
                                     clipboard (numbers + fixed labels only, on request)

 Licence key ──► POST api.gumroad.com/v2/licenses/verify {product_id, license_key, increment_uses_count}
            ◄── {success, uses, purchase.refunded/chargebacked/disputed}
            ──► localStorage["statement-xray-license"]
```

- **Statement contents never leave the browser.** They are not uploaded, stored or logged. They
  are gone when the tab closes.
- **Persisted state:** only the licence key, in `localStorage`.
- **Network requests:** Google Fonts (stylesheet and font files) on load, and Gumroad licence checks.
  Cloudflare and GitHub Pages serve the page.

## Key decisions

- **No server.** This keeps hosting free, means there is no user data to secure on a backend, and
  makes the "stays on your computer" promise true by construction. The cost is that the paywall
  can be bypassed by a technical user (accepted in `SETUP.md`; see `SECURITY_REVIEW.md` M3).
- **One file, no dependencies.** It runs unchanged in the claude.ai preview and on any static host.
  `build.sh` adds only the `<!doctype>`, charset, viewport and an http→https redirect that the
  preview supplies itself.
- **Licence check via Gumroad.** `increment_uses_count` is sent only on an explicit unlock, which
  caps a key at `SALE.maxDevices` browsers. The silent re-check on each load doesn't count as a
  use. It relocks only on a definite answer (invalid, refunded, charged back), so a saved key keeps
  working offline and through Gumroad outages or rate limits.
- **One currency per report.** When rows use several currencies, the most common one is reported
  and the others are listed as left out.
- **Sales tax/VAT collected from buyers is excluded**, because that money never belonged to the
  seller. VAT that Etsy charges on its own fees is a separate category.
- **Self-check.** The computed "kept" figure is compared against the sum of the statements' Net
  column. Any difference is shown, so most parsing mistakes surface. Rows dropped by the deduplication are
  missing from both sides, so the check can't catch them (`SECURITY_REVIEW.md` L4).

## Hosting

GitHub Pages serves `docs/` from `main`, with the custom domain in `docs/CNAME`. Cloudflare proxies
`xray.ausiejus.lt` and provides TLS. **Merging to `main` deploys**, because Pages republishes
whatever is in `docs/`.
